Steelshell — SSH-клиент для Windows, Android и терминала Linux.

Хосты, ключи, пароли и сниппеты живут в одном хранилище. Оно шифруется на вашем устройстве, поэтому сервер синхронизации видит только шифротекст.

2 терминал

Терминал, который не мешает работать.

  • Ctrl Shift D второй терминал рядом
  • ввод в оба одна команда сразу на два сервера
  • Ctrl Shift K палитра сниппетов
  • SFTP файлы рядом с консолью
  • Esc Tab Ctrl ←→ панель клавиш на телефоне

3 агенты

Дайте Claude Code сервер, а не пароль.

Агент читает логи, выполняет команды и правит файлы только на тех серверах, которые вы открыли. Адресов, паролей и ключей он не видит, а каждый вызов записывается в журнал.

в Claude Code
/plugin marketplace add steelshell/claude-plugin
/plugin install steelshell@steelshell
