An SSH client in a steel shellSSH-клиент в стальном корпусе

Hosts, keys, passwords and snippets live in one vault and follow you to every device you sign in on: Windows, Android and the Linux terminal. Everything is encrypted on the device, so the sync server only ever receives ciphertext.Хосты, ключи, пароли и сниппеты лежат в одном хранилище и есть на каждом устройстве, где вы вошли: в Windows, на Android и в терминале Linux. Всё шифруется ещё на устройстве, поэтому сервер синхронизации получает только шифротекст.

Only you hold the keyКлюч от корпуса есть только у вас

The sync server keeps your records like sealed, numbered envelopes. It can tell how many there are, of what kind and when they arrived, but it can't open them: the vault key exists only on your devices.Сервер синхронизации хранит записи как запечатанные конверты с номерами. Он видит, сколько их, какого они типа и когда пришли, но открыть не может: ключ хранилища есть только на ваших устройствах.

Even someone who takes over that server gets a stack of envelopes and nothing to open them with.Даже тот, кто захватит этот сервер, получит стопку конвертов и ничего, чем их открыть.

Technical requirementsТехнические требования

  1. Your password never leaves the device. Argon2id with 64 MiB and two passes turns it into a sign-in key and the key that seals your vault key.Пароль не покидает устройство. Argon2id с 64 МиБ и двумя проходами делает из него ключ входа и ключ, которым запечатан ключ хранилища.
  2. Every record is encrypted with AES-256-GCM and bound to its kind and id, so one record can't be passed off as another.Каждая запись зашифрована AES-256-GCM и привязана к своему типу и номеру, поэтому одну запись нельзя выдать за другую.
  3. A new device gets the vault key sealed with X25519 for that device alone. Its sign-in code is derived from the device's own key.Новое устройство получает ключ хранилища, запечатанный X25519 только для него. Код входа выводится из ключа самого устройства.
  4. Clients refuse weaker encryption settings even when the server asks for them.Клиенты не принимают ослабленные параметры шифрования, даже если их просит сервер.
  5. An AI agent works through Steelshell and never sees a password or a key.ИИ-агент работает через Steelshell и не видит ни паролей, ни ключей.

The Linux terminal and AI agentsТерминал Linux и ИИ-агенты

steelshell installs on Debian and Ubuntu with one command. Once you sign in, your servers, keys and snippets are there: steelshell ssh, exec, cp and a full-screen view.steelshell ставится на Debian и Ubuntu одной командой. После входа в нём ваши серверы, ключи и сниппеты: steelshell ssh, exec, cp и полноэкранный режим.

Its MCP server lets Claude Code and other agents work only on the servers you open to them. The agent keeps a shell open, runs commands and edits files, Steelshell signs in for it, and every step goes into a log.Встроенный MCP-сервер даёт Claude Code и другим агентам работать только на серверах, которые вы им открыли. Агент держит сессию, запускает команды и правит файлы, Steelshell входит на сервер за него и пишет каждый шаг в журнал.

curl -fsSL https://steelshell.dev/install.sh | sh

Install. Updates come through apt after that.Установить. Обновления потом приходят через apt.

steelshell login

Sign in with a link, or type the code in the app.Войти по ссылке или по коду в приложении.

steelshell agent allow prod-api

Let agents work on one server.Открыть агентам один сервер.

steelshell agent setup

Connect Claude Code.Подключить Claude Code.
