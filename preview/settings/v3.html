Steelshell · Settings redesign

Live preview

Settings becomes a two-pane workbench: every control sits inline in one column of grouped cards, and the right half of the window holds a live mini terminal and host list that redraw while you change them. Theme, font, size, cursor, status bar, suggestions and server status are visible before you leave Settings, and a sticky index with search keeps every section one click away. Agent access uses the same split, with per-server access on the left and exactly what Claude Code and Codex can see on the right. On the phone a small terminal strip stays pinned over the list and opens up while you are in Terminal.

What changes for you

  • Appearance, language, font, size, cursor and scrollback are set in place, with no subpage per value
  • Terminal gets its own section, out of Appearance, with all 14 themes visible as swatches
  • You see the terminal and the host list change as you click, in the real theme, font and size
  • The account card shows sync status and devices; AI agents get a status card with the master switch
  • Search and a section index replace one 25-row scroll, and the empty right half now does work
  • Agent access shows what agents see: visible servers, their access level and what stays hidden

Try it: click a theme swatch, a cursor style, the font size stepper, the status bar or suggestions switch, or change a server's access on the Agent access page.
