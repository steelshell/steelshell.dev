R2Уведомления

Одобрять из уведомления только после разблокировки

R20Тексты

Тексты подтверждений: конкретно и одинаково в en и ru

«Разрешить это на {host}?» не говорит, что именно разрешается, «Запрет через 1:42» звучит как приказ, а «Claude Code просит разрешения использовать Bash:» называет инструмент вместо действия. Один и тот же отказ подписан то «Запретить», то «Отклонить», а раздел — то «Подтверждения», то «Разрешения».

Например: «Разрешить команду на {host}?» / «Run this command on {host}?», «Автоотказ через 1:42» / «Auto-deny in 1:42», «Claude Code хочет выполнить команду».
