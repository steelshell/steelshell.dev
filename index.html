Steelshell keeps hosts, keys, passwords and snippets in one vault, encrypted on your device. Sign in on Windows, Android or in a Linux terminal and they are already there. Your password stays on your deviceПароль не покидает устройство
It goes through Argon2id with 64 MiB of memory. The server receives a key derived from it, never the password itself.Он проходит через Argon2id с 64 МиБ памяти. Сервер получает только выведенный из него ключ, а не сам пароль.
Each item is sealed on its ownКаждая запись шифруется отдельно
AES-256-GCM with your vault key, bound to the item's id, so records can't be swapped for one another.AES-256-GCM ключом хранилища с привязкой к id записи, поэтому записи нельзя подменить друг другом.
New devices sign in with your approvalНовые устройства входят с вашего разрешения
A server can sign in from a link: your browser encrypts the vault key for that device's one-time X25519 key, and the server only passes it on.Сервер может войти по ссылке: браузер шифрует ключ хранилища для одноразового X25519-ключа этого устройства, а сервер только передаёт его.
Only you can recover itВосстановить можете только вы
Steelshell can't reset your vault. The recovery key you write down when you sign up is the way back in.Steelshell не может сбросить хранилище. Вернуться можно по ключу восстановления, который вы записываете при регистрации.

Let an AI agent fix a server without handing it the passwordАгент чинит сервер, а пароль остаётся у вас

Steelshell runs an MCP server for Claude Code, Codex and Cursor. The agent reads logs, runs commands and edits files on the servers you share, and never sees an address, a password or a key.Steelshell запускает MCP-сервер для Claude Code, Codex и Cursor. Агент читает логи, выполняет команды и правит файлы на серверах, которые вы открыли, и не видит ни адресов, ни паролей, ни ключей.

You decide per server: read only, or commands and file edits too. Passwords and tokens in the output are hidden from the agent, and every call goes into a log that steelshell agent log shows.Для каждого сервера вы решаете сами: только чтение или ещё команды и правка файлов. Пароли и токены в выводе скрываются от агента, а каждый вызов попадает в журнал, его показывает steelshell agent log.
